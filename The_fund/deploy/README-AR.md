# نشر الصندوق على خادم سحابي مجاني (Oracle Always Free)

المطلوب منك: **حساب + إنشاء جهاز افتراضي + فتح منفذين**، ثم ملفان تنقر عليهما. الباقي تلقائي.

## أولاً: الخادم المجاني (مرة واحدة، من متصفحك)

1. أنشئ حساباً في Oracle Cloud (cloud.oracle.com ← Sign up).
   - يطلب **بطاقة للتحقق فقط** (تُحجز عادةً 1$ ثم تُعاد). قد يرفض بعض البطاقات أو البلدان.
   - **اختر «Home Region» بعناية**: لا يمكن تغييرها لاحقاً.
2. أنشئ جهازاً: **Compute ← Instances ← Create instance**
   - Image: **Ubuntu 22.04 أو 24.04**.
   - Shape: **VM.Standard.A1.Flex** (ARM مجاني، 1–2 نواة و6–12GB). إن ظهرت «Out of capacity» جرّب نطاق توفّر (Availability Domain) آخر أو أعد المحاولة لاحقاً، أو استخدم **VM.Standard.E2.1.Micro** (ذاكرة 1GB، يكفي هذا النظام، وسكربت التثبيت يضيف swap تلقائياً).
   - Networking: أبقِ **Assign a public IPv4 address** مفعّلاً.
   - SSH keys: اختر **Generate a key pair** ثم **Save private key** (احفظ الملف، ستحتاجه).
3. **افتح المنفذين 80 و443** (خطوة لا يمكن أتمتتها): من صفحة الجهاز اضغط اسم الـ **Subnet** ← **Security Lists** ← الافتراضية ← **Add Ingress Rules**:
   - Source CIDR: `0.0.0.0/0` — Protocol: TCP — Destination Port: `80`
   - ثم قاعدة ثانية بنفس الشكل للمنفذ `443`.
4. **تجنّب ضياع الجهاز بسبب الخمول:** تسترد Oracle أحياناً أجهزة Always Free قليلة الاستخدام (استهلاك معالج منخفض لأيام). الحل المتّبع: حوّل الحساب إلى **Pay As You Go** من لوحة التحكم؛ تبقى الموارد ضمن الحد المجاني بلا رسوم، لكن راجع شروط Oracle الحالية قبل ذلك.

## ثانياً: تثبيت الخادم (تلقائي)

افتح PowerShell داخل مجلد المشروع `The_fund` ثم:

```powershell
.\deploy\deploy.ps1
```

سيسألك عن: عنوان IP العام للجهاز، واسم المستخدم (`ubuntu`)، ومسار ملف المفتاح الذي حفظته.

يقوم تلقائياً بـ: رفع الخادم، تثبيت Docker، فتح المنفذين في جدار الجهاز، توليد مفاتيح التشفير وكلمة مرور المدير، تشغيل الخادم، إصدار شهادة HTTPS مجانية (عنوان من نوع `1-2-3-4.sslip.io` فلا تحتاج شراء نطاق)، وجدولة نسخ احتياطي يومي.

في النهاية يطبع **عنوان الخادم وكلمة مرور المدير**، ويحفظها في `deploy\server-info.txt`.

> **انسخ `deploy\server-info.txt` إلى مكان آمن خارج الحاسوب.** فيه `ENCRYPTION_KEY`: ضياعه يعني ضياع أرقام الهوية والهواتف المشفّرة نهائياً.

لنطاق خاص بك: `.\deploy\deploy.ps1 -Domain app.mydomain.com` (بعد توجيه النطاق إلى IP الجهاز).

## ثالثاً: بناء التطبيق (تلقائي)

```powershell
.\deploy\build-apk.ps1
```

يقرأ عنوان الخادم تلقائياً، وينشئ مفتاح التوقيع أول مرة، ثم يبني `deploy\SocialFund.apk`.

> **انسخ مجلد `deploy\secrets` إلى مكان آمن**: فيه مفتاح توقيع التطبيق. ضياعه يمنعك من تحديث التطبيق لاحقاً.

## رابعاً: أول استخدام
1. ثبّت الـAPK وسجّل الدخول بـ `admin` وكلمة المرور المطبوعة، ثم **غيّرها فوراً** من الإعدادات.
2. أنشئ شجرة الحسابات من «الحسابات والبنوك».
3. افتح «العملات وأسعار الصرف» وأدخل الأسعار وفعّل ما تحتاج.

## الصيانة
- **تحديث الخادم:** أعد تشغيل `deploy.ps1` (تبقى المفاتيح والبيانات).
- **النسخ الاحتياطية:** على الخادم في `/opt/socialfund/backups` (آخر 14 يوماً). والنسخة اليدوية من الإعدادات داخل التطبيق.
- **حالة الخادم:** `https://عنوانك/health` يجب أن يعيد `ok`.
- **السجلات:** `ssh ubuntu@IP "cd /opt/socialfund && sudo docker compose logs --tail 50"`.
